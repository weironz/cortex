# Cortex UI 落地清单

设计稿：`Cortex UI macOS 版.dc.html`（13 屏，浅色/深色）。
这份清单是给在 `cortex/app` 里动手的人看的 —— 说清**改哪里、为什么改**，不重复设计稿里已经能看到的东西。

---

## 一、Token（`app/lib/core/theme.dart`）

现状是中性优先的 M3 + 靛蓝。要改的是这几条：

| 角色 | 现在 | 改成 | 为什么 |
| --- | --- | --- | --- |
| 圆角基准 | M3 默认（4/8/12 混用） | 窗口 14 / 卡片 13 / 输入框 18 / 行 9 / chip 999 | 五档成体系，不再逐个组件拍脑袋 |
| 中性色 | 偏暖灰 | 冷调：`#17171A` / `#5E5E68` / `#63636C`，分隔线 7% 黑 | 与 macOS 的 sidebar/content 分层一致 |
| 主色 | 单一靛蓝 | `--acc #5B62F4`，渐变只留发送键一处 | 渐变一多，「主要动作」就不再突出 |
| **等你确认** | **无** | **琥珀 `#B7791F`**，新增一档 | 见下节，这是最重要的一条 |
| 失败 | 红 `#D2444C` | 红 `#BC2E38`（浅色） | 原值在 fill 上只有 4.1:1，比旁边的绿弱一档 |

深色一整套在设计稿的 `DARK` 常量里，照抄即可。

## 二、状态色必须有第四档

`AgentStatus` 现在是 running / finished / failed 三态。界面上还需要第四态：**awaiting_confirm**。

它是唯一一个「不处理就永远卡住」的状态，却和 running 共用蓝色 —— 人扫一眼分不出「在跑」和「在等我」。

落点三处，必须同色（琥珀）：
1. 左栏会话行的状态点
2. 顶栏的「等你确认 · N」pill
3. 系统托盘图标

## 三、要拆的 widget

- **`message_composer.dart`（692 行）** —— chip 那一排要能收：窄屏只留「目录」「权限档」两颗，其余进「…」。现在是固定 flex，放不下就溢出。
- **`chat_pane.dart` 的右栏** —— 从「只放文件」改成三页签：文件 / 本轮改动 / 终端。长 diff 现在只能在气泡里看，会把对话挤成一条缝。代码卡片右上角加「在右栏打开」。
- **`nav_block.dart` + 会话列表** —— 合成一棵可折叠的树：置顶 / 项目（含子项目）/ 最近。最近固定在最下、默认展开。
- **设置** —— 改成整屏路由（进去不留应用侧栏），导航分 模型 / 工具 / 偏好 / 系统 四组。

## 四、新增的屏

| 屏 | 说明 |
| --- | --- |
| 首次启动 | **不单独做一屏**。模型走免费额度（Cortex Mini）、工作目录自动建在 `~/Cortex` —— 唯一还要动手的「连服务器」就是登录页本身，再插一屏只是多一次点击。第一次打开直接落在登录页，「先离线用」是不连也能走的出口。 |
| 失败态 ×3 | 模型失败（重试／换模型）、工具失败（stderr 可展开、让它自己修）、连接断了（说清哪几步已落盘）。红只用在标题行。 |
| 命令面板 ⌘K | 一个输入框管四件事，前缀区分：`>` 命令、`@` 文件、`/` 技能。 |
| 窄屏 | 左栏从左抽出、文件栏从**底部**抽上来（从右边推会和系统手势打架）。 |

## 五、密度

桌面端加「紧凑」一档：行高 −6px、正文 14px/1.66。默认档不动 —— 长回答需要那个行距。

## 六、不要做的

- 不要把渐变铺回主按钮和头像；
- 不要给确认面板统一样式 —— 风险三档（读 / 执行 / 放行）的边框强度必须不同，判据是**爆炸半径**，不是「错误多严重」；
- 关掉的技能整行压暗到 0.45，别和开着的长一样（它在提示词里根本不存在）。
